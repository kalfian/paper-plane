MCP server

Let AI clients such as Claude Code, Claude Desktop or Cursor manage your projects and files over the Model Context Protocol.

Transport
Streamable HTTP (POST, JSON responses)
Authentication
Authorization: Bearer <token>, using an access token whose scope includes MCP (REST API + MCP or MCP only).

Create a token from the CLI

Prefer the terminal? The server binary prints a new token, shown once, just like this page.

Binary 
paperplane token create --name claude --scope mcp
Docker Compose 
docker compose exec paperplane /paperplane token create --name claude --scope mcp
